## 🧭 O que é um repositório?

Um **repositório** é um espaço online (como o GitHub) usado para **armazenar, versionar e compartilhar** o código de um projeto.  
Ele permite acompanhar as mudanças feitas ao longo do tempo e colaborar com outras pessoas de forma organizada.

---

## 🚀 Como dar Deploy?

O **deploy** é o processo de colocar o site no ar.

1. Certifique-se de que o arquivo inicial do site se chama `index.html`.  
   Esse será o arquivo carregado automaticamente na página principal.

2. Envie as alterações para o GitHub (veja seção abaixo).  
   Se o repositório estiver configurado com **GitHub Pages**, o site será publicado automaticamente.

3. Para habilitar o GitHub Pages:
   - Vá até **Settings → Pages**.  
   - Em **Source**, selecione a branch principal (geralmente `main`) e clique em **Save**.
   - Essa parte não é necessária, uma vez que o deploy já foi feito!

O site ficará disponível em:  
👉 `https://procipy.github.io/website`

## 🧑‍💻 Alterações no Site e Uso do Git, GitHub e GitHub Desktop

### 🔹 Instalar o GitHub Desktop
Ultilisa-se o GitHub Desktop para puxar o repostório para usa máquina, e realisar alterações, assim como devolver o repositório alterado para o github.

Baixe e instale o **GitHub Desktop**:  
➡️ [https://desktop.github.com/download/](https://desktop.github.com/download/)

### 🔹 Clonar o repositório
1. Abra o GitHub Desktop.  
2. Vá em **File → Clone Repository**.  
3. Cole o link do repositório: [https://github.com/Procipy/website](https://github.com/Procipy/website)

4. Escolha uma pasta local para salvar o projeto.

### 🔹 Fazer alterações
1. Abra o projeto no seu editor (VS Code, Sublime, etc).  
2. Edite os arquivos `.html`, `.css` e `.js` conforme necessário.  
3. Mantenha o arquivo principal como `index.html`.

### 🔹 Enviar alterações
1. Após editar, volte ao GitHub Desktop.  
2. Digite uma mensagem de commit descrevendo a alteração.  
3. Clique em **Commit to main**.  
4. Depois, clique em **Push origin** para enviar ao GitHub.

## 📂 Estrutura de Pastas do Repositório

A estrutura básica do site deve seguir este formato:
No root teremos o index.html
Para cada página de ementa individual cria-se uma pasta para por os seus arquivos html e css individuais.


📌 **Importante:**  
O arquivo `index.html` deve ser mantido na raiz do projeto — ele será carregado automaticamente ao acessar o site.

## 🧪 Como testar o site antes de enviar para o GitHub?

Antes de subir suas alterações, é recomendável testar o site localmente.

### Usando o Live Server (VS Code)
1. Instale a extensão **Live Server** no VS Code.  
2. Clique com o botão direito em `index.html` → **Open with Live Server**.  
3. O site abrirá no navegador em `http://localhost:5500`.
